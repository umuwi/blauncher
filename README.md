# BLauncher

**Бесплатный лаунчер Minecraft: Java Edition. Без рекламы, без платных функций, Java уже внутри.**

Любая версия Minecraft, моды и модпаки в один клик, игра с друзьями без настройки роутера, свой
сервер на компьютере или VPS, редактор скинов — и Minecraft, переписанный на Rust.

## 🎮 Игра без лишних шагов

- **Любая релизная версия** Minecraft Java Edition — от самых старых до 26.x. Файлы игры качаются
  напрямую с серверов Mojang.
- **Можно без лицензии**: играй с любым ником. Есть вход через Microsoft — для серверов, которые
  пускают только лицензионных игроков.
- **Java подбирается сама**: Java 8 для старых версий, новая — для свежих. Если мод требует Java
  новее, лаунчер сам перезапустит игру на подходящей и запомнит выбор.
- **Несколько профилей** со своими никами, скинами и плащами.
- **Память подбирается сама** кнопкой «Рекомендуемое»; у каждой сборки можно задать свою.
- **Тихое автообновление**: лаунчер обновляется сам, когда ты его закрываешь.
- **Уведомления**: запросы в друзья и приглашения приходят в колокольчик с кнопками «Принять» и
  «Отклонить».

## 🦀 Minecraft на Rust

На карточке «Без модов и сборок» можно выбрать **язык игры**:

- **Java** — обычный Minecraft, с модами и без.
- **Rust** — Minecraft 26.3 на движке **Rustcraft**, переписанном с Java на Rust. Быстро
  запускается и работает **без лицензии**. Нужна видеокарта с Vulkan или DirectX 12. Если движок
  не запустился, лаунчер сам вернёт обычную Java.
- **Horizon** — ещё одна версия Minecraft 26.3 на Rust, для владельцев лицензии. Поддерживает моды
  на Rust, которые лаунчер собирает сам.

Подробно: [blauncher.ru/rust](https://blauncher.ru/rust/).

## 📦 Моды, сборки и модпаки

- **Сборки** — отдельные профили со своими модами, ресурспаками, шейдерами и датапаками.
- **Forge, Fabric, NeoForge, Quilt и OptiFine** ставятся сами, старые версии Forge (1.7.10–1.16.5) тоже.
- **Поиск модов с Modrinth прямо в лаунчере**: моды, шейдеры, ресурспаки, датапаки и модпаки, с
  фильтром по версии и загрузчику. Описания модов переводятся на русский.
- **Модпаки в один клик**: лаунчер сам создаёт сборку с нужной версией и загрузчиком.
- **.mrpack**: сохрани сборку в файл, открой чужую или поделись ссылкой.
- **Fabric API** добавляется сам, недостающие библиотеки докачиваются.
- **Эксклюзив**: бета-порт мода **Create** на Minecraft 26.3 для NeoForge и Fabric.

## 🔧 Починка сборки

Игра с модами вылетела? Лаунчер сам разберёт журнал и файлы модов и предложит **«Починить и
запустить»**:

- докачает недостающий мод или библиотеку — частые случаи чинит сам, без вопросов;
- уберёт дубликаты;
- выключит мод, который не подходит к версии или загрузчику;
- отложит сломанный файл настроек;
- объяснит по-человечески, что случилось: не хватает памяти, занят порт, мод требует другую Java…

Мод не удаляется, а выключается — его легко вернуть. Проверить сборку можно и заранее, кнопкой
«Проверить и починить моды».

## 👥 Друзья и игра вместе

- **Друзья по коду**: кто в сети, профиль со скином.
- **Комнаты «Играть вместе»** — своя виртуальная сеть на основе ZeroTier. Создаёшь комнату, зовёшь
  друзей приглашением или ссылкой, открываешь мир — друзья заходят, как по локальной сети. Роутер
  и порты настраивать не нужно. Комнаты бывают открытые и закрытые, с входом по одобрению.
- **Миры друзьям**: отправь свой мир другу, и он сразу сможет в него играть или поднять на нём
  сервер.
- **Общий список серверов** игроков BLauncher.

## 🖥 Свой сервер: на ПК, на VPS или купить

- **На компьютере** — сервер в один клик со своей сборкой: консоль, список игроков, настройки
  server.properties понятными плитками. Ядра Vanilla, Paper, Purpur, Folia, Fabric, Forge и
  NeoForge.
- **Мир сервера**: выбери, какой мир запускать, создай новый или возьми мир из одиночной игры.
- **Доступ друзьям** через туннель playit.gg или ZeroTier — без проброса портов.
- **На VPS** — впиши адрес и пароль арендованного сервера, и лаунчер сам поставит Java и Minecraft,
  настроит автозапуск и брандмауэр. Дальше всё из лаунчера: консоль, моды и плагины, бэкапы, перенос
  сервера с ПК, несколько серверов на одном VPS, перезапуск по расписанию. Агент на VPS обновляется
  сам. [Инструкция](https://blauncher.ru/vps.html).
- **Купить сервер** — тарифы хостинга serv.host в 27 странах прямо во вкладке.

## 🎨 Скины, студия и инструменты

- **3D-редактор скинов и плащей**: рисуешь прямо на модели и сразу ставишь в профиль. Плащи в
  высоком разрешении, скины видны другим игрокам BLauncher.
- **Студия предметов и блоков**: собери сцену из блоков, предметов и текста в 3D, сгруппируй,
  анимируй по кадрам — и получи готовую команду для командного блока или датапак прямо в мир.
  Можно открыть существующую команду /summon.
- **Связка с Blender**: отправь постройку в Blender с настоящими блоками и верни обратно без потерь.
- **Оформление**: темы (тёмная, чёрная, светлая), своя палитра, фоны, масштаб шрифта.
- **Русский и английский** интерфейс.

## 💻 Системы

| Система | Что работает |
|---|---|
| **Windows 10/11** (64-бит) | всё, что описано выше; установщик ~55 МБ |
| **Linux** x86_64 — бета | тот же лаунчер; комнаты и playit.gg пока только в Windows |
| **Android 8+** arm64 — бета | Minecraft Java Edition от 1.0 до 26.2, моды, загрузчики, свой сервер; без Rust |

Установщик для Windows не подписан платной подписью, поэтому Windows может предупредить при
запуске: нажми «Подробнее» → «Выполнить в любом случае». Подробности — в
[вопросах на сайте](https://blauncher.ru/).

## Для разработчиков

### Сборка

Нужны Windows, [JDK 21](https://adoptium.net/) и PowerShell. Системы сборки вроде Maven или Gradle
нет: всё делают два скрипта.

```powershell
git clone https://github.com/umuwi/blauncher.git
cd blauncher
.\fetch-libs.ps1                              # сторонние jar с Maven Central → app\ и lib\
.\build.ps1 -Version v0.0.0-dev -SkipManifest # → app\BLauncher.jar
java -cp "app\*" com.example.launcher.AppLauncher
```

- `app\` — classpath лаунчера (JavaFX, Gson, BouncyCastle, ASM, Ikonli).
- `lib\` — библиотеки, которые `build.ps1` распаковывает **внутрь** `BLauncher.jar`
  (декодер WebP, JSch для SSH). Автообновление заменяет только `BLauncher.jar`, поэтому новые
  зависимости добавляются сюда, а не в `app\`.
- Данные лаунчер пишет относительно рабочей папки: `launcher_root\` (сборки, моды, миры, серверы)
  и `config\`. Для экспериментов запускайте его из пустой временной папки.
- Без `-SkipManifest` `build.ps1` пишет манифесты автообновления — это шаг релиза.
- `build-installer.ps1` собирает установщик (`installer\`, C# 5, `csc` из .NET Framework); ему нужен
  app-image от `jpackage` в `dist\BLauncher`. Подробности — в [installer/README.md](installer/README.md).
- `build-linux.sh` собирает архив для Linux.
- `blcore\` — мод-компаньон для Fabric (значки и плащи игроков BLauncher), собирается Gradle;
  готовый jar лежит в `src/main/resources/blcore/`.

### Устройство

```
src/main/java/com/example/launcher/
  AppLauncher, MainApp     точка входа
  controller/              UI: MainController (основной экран) и вынесенные панели
  service/                 логика без JavaFX: запуск игры и сервера, загрузчики, Modrinth,
                           версии, Java, обновления, ZeroTier, playit, Rustcraft, Horizon
  service/vps/             сервер на VPS по SSH
  agent/                   клиент VPS-агента
  model/                   модели для Gson
  ui/                      компоненты: анимации, редактор скина, студия предметов
src/main/resources/
  fxml/main.fxml           разметка
  css/theme-template.css   тема; цвета подставляет PaletteService из палитры
  i18n/                    строки интерфейса
```

Серверная часть blauncher.ru (обновления, друзья, статистика) и Android-версия в этот репозиторий
не входят.
